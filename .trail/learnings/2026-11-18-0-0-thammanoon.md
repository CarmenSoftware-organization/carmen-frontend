## Decided
- 2026-11-18 แท็บ Stock Movement ของ GRN เลือกรูปแบบตามความกว้างกล่อง: < 600px การ์ดแถวละใบ (จำนวน+หน่วยในช่องเดียว "0 PCS") · 600–1100px ตารางสัดส่วนเดิม · >= 1100px คอลัมน์สินค้า grow ที่เหลือกว้างคงที่
- เลขจำนวน 0 แสดงเป็น 0 — ใบที่ยังไม่ลงสต๊อก ข้อความเหนือตารางบอกว่า "เป็นศูนย์" ถ้าขึ้นขีดจะขัดกัน

## Tried and ruled out
- ตาราง 8 คอลัมน์บนมือถือ: บีบเหลือคอลัมน์ละ 29–64px ชื่อสินค้า/ราคาถูกตัดเหลือไม่กี่ตัว
- grow ทุกความกว้าง: grow ล็อกตารางที่ผลรวม size (1040px) กล่องแคบกว่านั้นต้องเลื่อนแนวนอน

## Watch out
- FieldPlainText แสดง "—" เมื่อ children เป็น falsy — ส่งตัวเลขที่อาจเป็น 0 ต้องแปลงเป็น string ก่อน
- ใบใน dev DB (T02) ที่มีแถวสต๊อกเป็น not posted ทุกใบ ตัวเลขเป็น 0 หมด ยังไม่ได้ดูใบที่ลงสต๊อกจริง · ตอนโหลดบนมือถือยังเป็นโครงตารางก่อนสลับเป็นการ์ด
