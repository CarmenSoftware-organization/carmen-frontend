## Decided
2026-11-13 ผู้ใช้สั่ง optimize skill carmen-blue-ui-design และเลือกแนว "ลดขนาด + ตัดของซ้ำ" ไฟล์หลักของ skill โหลดเต็มทุกครั้งที่เรียก (48 ครั้งใน 2 วัน) และโตขึ้นเพราะทุกหน้าที่ทำเสร็จเติมกับดักเข้าไฟล์หลักตรง ๆ จึงจัดใหม่: ไฟล์หลักเหลือตารางชนิดหน้า กติกา 13 ข้อ ของที่มีอยู่แล้ว ตัวอย่างหนึ่งหน้าต่อชนิด และกับดักที่ใช้กับทุกหน้าเท่านั้น กับดักเฉพาะฟอร์ม / ลิสต์ / ตาราง / landing ย้ายไปอยู่ในสูตรของชนิดหน้านั้น ไฟล์หลักลดจาก ~3.7k เหลือ ~2k token โดยประมาณ

เมื่อทำหน้าใหม่เสร็จแล้วเจอกับดักใหม่: ถ้าเกิดได้กับหน้าทุกชนิดค่อยใส่ไฟล์หลัก ถ้าเกิดเฉพาะชนิดหน้าใดให้ใส่ใต้หัวข้อของชนิดนั้น และไม่ต้องใส่วันที่ ชื่อหน้าที่มา หรือเลข PR

## Tried and ruled out
- ย้ายที่อย่างเดียวโดยไม่ตัดของซ้ำ: ผู้ใช้ไม่เลือก เพราะยังเหลือกับดักที่พูดซ้ำกับไฟล์ย่อย และประวัติที่ไม่ใช่คำสั่ง
- ทดสอบกับ subagent ก่อนว่าพลาดกติกาข้อไหนแล้วแก้เฉพาะจุด: ผู้ใช้ไม่เลือกในรอบนี้ จึง**ยังไม่ได้ทดสอบ**ว่า agent เปิดสูตรของชนิดหน้าเองจริงหลังย้าย

## Watch out
- กับดักตาราง (งบความกว้างที่ tablet, คอลัมน์ select ที่ถูกนับแม้ไม่แสดง) เคยโหลดทุกครั้ง ตอนนี้เห็นได้ก็ต่อเมื่อเปิดสูตรตาราง ถ้าพบว่างานตารางเริ่มล้นที่ tablet อีก ให้สงสัยจุดนี้ก่อน
- กฎเขียน skill ส่วนตัวของผู้ใช้ให้ไฟล์หลักไม่เกิน 120 บรรทัด ตอนนี้อยู่ที่ 115
