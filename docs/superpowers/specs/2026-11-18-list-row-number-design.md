# เลขลำดับแถวทุกหน้ารายการ (ตาราง + การ์ด) — design

วันที่ 2026-11-18 · ขนาด: งานเล็กเชิงแนวคิด แต่แตะหลายไฟล์ (pattern เดียวซ้ำ)

## เจตนา

ผู้ใช้ใช้เลขลำดับ **อ้างอิงแถวเวลาคุยกัน** ("แถวที่ 27") — คนหนึ่งอาจดูตาราง อีกคนดูการ์ด
หรือคนละขนาดจอ เลขของรายการเดียวกันต้องตรงกันเสมอ

## เป้าหมาย / ไม่ใช่เป้าหมาย

- ทุก **หน้ารายการ** มีเลขลำดับ ทั้งมุมมองตาราง (คอลัมน์ `#`) และมุมมองการ์ด (`#27` หน้าชื่อการ์ด)
- เลข **นับต่อข้ามหน้า**: `(page − 1) × perpage + index + 1`; หน้าที่ใช้ "โหลดเพิ่ม" = ลำดับในรายการสะสม + 1
- ตารางกับการ์ดใช้สูตรจากฟังก์ชันเดียวกัน
- **แสดงตลอดทุกขนาดจอ** (ผู้ใช้เลือกข้อ A) — ไม่ซ่อน `#` เมื่อกล่องแคบอีกต่อไป
- ไม่ใช่เป้าหมาย: ตารางในฟอร์ม / dialog / wizard (ส่วนใหญ่มี `#` อยู่แล้ว) · เลขที่คงที่ข้ามการเรียง/กรอง
  (เลขผูกกับมุมมองปัจจุบัน การอ้างข้ามมุมมองใช้เลขเอกสารตามเดิม)
- Anti-goal: เลขในตารางกับการ์ดของรายการเดียวกันไม่ตรงกัน

## Approaches

1. **ส่งเลขผ่าน prop ทีละหน้า** — ✅ เลือก: ตรงไปตรงมา ตาม pattern เดิม เลขคัดลอกได้ / screen reader อ่านได้
2. CSS counter — ตัดทิ้ง: `::before` คัดลอกไม่ได้, a11y ไม่แน่นอน, skeleton/การ์ดซ่อนทำเลขเพี้ยนเงียบ, ยังต้องแตะ wrapper ทุกหน้า และไม่ช่วยตาราง
3. `DataGrid` ใส่ `#` อัตโนมัติ — ตัดทิ้ง: ซ้ำกับ `#` ของตารางในฟอร์ม ต้องไล่ปิด และงบความกว้างทุกตารางเพี้ยนพร้อมกัน

## การออกแบบ (ที่ตกลงแล้ว)

- แยกสูตรจาก `indexColumn()` (`components/ui/data-grid/columns.tsx`) เป็น `rowNumber(params, index)`
  ให้ `indexColumn` เรียกตัวนี้
- `ListCard` (`components/share/list-card.tsx`) รับ prop `index?: number` แสดง `#27` สีจาง
  (`text-muted-foreground tabular-nums`) หน้าชื่อการ์ด ไม่ส่ง = ไม่แสดง (backward-compatible)
- ไล่ทุกหน้าที่ใช้ `ListCard` (~57) ส่งเลขจาก `rowNumber()` หรือ index สะสมของ load-more
- ตารางรายการที่ยังไม่มี `#` (~20 หน้า เช่น AR folio/receipt/contract, accounting document/register,
  GL period, JV prefix, bank account, asset category, sales consumption, POS import history,
  report history/list/schedules) ใส่ `indexColumn`; ถอด `hideIndex: true` ของ AP master
- ตารางที่ซ่อน `#` ตามความกว้างกล่อง (Vendor, Certification, RFP, PRT, Document): เอา `#` ออกจาก tier
  ให้คอลัมน์รองหายแทน แล้วคำนวณจุดเปลี่ยน tier ใหม่ (วัดที่ 768/1024/1180/1280/1366 + 5 ขนาดมาตรฐาน)

## ข้อเสนอของ Claude (แก้ได้)

- ลดความกว้าง `indexColumn` จาก 60 → ~48px (ตัวเลข 4 หลัก + padding ยังพอ) — ต้องปรับงบความกว้างของ
  `useConfigListTable` (`hideIndex ? 0 : 60`) ตาม
- แบ่ง PR: (1) helper + ListCard + ตารางที่ขาด · (2) การ์ดทุกหน้า · (3) ตาราง tier 5 หน้า
- ตรวจ: typecheck + lint + browser (ตาราง/การ์ดเลขตรงกัน, หน้า 2 เริ่ม 11, load-more ต่อเนื่อง, dark mode)

## เหลือให้ผู้ลงมือ

- หน้า card ไหนที่ไม่ได้ใช้ `ListCard` (การ์ดเขียนเอง) — ใส่ `#` ในตำแหน่งเทียบเท่า
- หน้าที่ perpage ไม่ได้มาจาก `params` (client-side pagination) ใช้ pageIndex/pageSize ของตารางแทน
